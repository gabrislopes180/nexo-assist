# Checkbox

Caixa de seleção de 18px com rótulo em `ink-2`. Marcada, fica em `cta` com `check` branco de 12px. É o "Manter conectado neste computador" do login.

- O consumidor fornece `label` e `checked` / `onChange` (ou `defaultChecked`).
- O estado desmarcado não aparece no protótipo: aqui ele usa borda `line-radio` em `paper` (ver Adições intencionais).
