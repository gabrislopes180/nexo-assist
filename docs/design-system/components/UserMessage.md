# UserMessage

Mensagem do funcionário no chat: bolha `ink` alinhada à direita, com texto `on-ink` em `body` e o canto inferior direito em `radius-xs`.

- O consumidor fornece o texto (`children`). A bolha cresce com o conteúdo até `user-bubble-width` (520px).
- Use só no chat do funcionário. No console do analista, a mensagem do cliente fica à esquerda, em `paper`.
